📖 Justifikasi AI

🧠 Metode AI

Forward Chaining (Symbolic AI) — rule engine adalah inti deteksi. LLM (Gemini) hanya berfungsi sebagai explainer, bukan pembuat keputusan. Ini memastikan sistem bersifat deterministic dan explainable.

🔍 Explainability

Setiap violation traceable ke rule_id spesifik. Audit trail dijamin dengan field rule_id di setiap feedback LLM, sesuai proposal §4.2 (Russell & Norvig 2010).

📦 Zero Dependencies

Seluruh rule engine hanya menggunakan Python standard library: ast, collections, difflib, itertools, dataclasses, enum. Cukup Python 3.8+, tanpa install apapun.

✅ Sifat Engine

Deterministik: input sama → output sama. Monotonic: violation tidak dicabut. Data-driven: dimulai dari fakta (AST node), bukan goal. Quiescence tercapai saat semua node × rule selesai dievaluasi.
